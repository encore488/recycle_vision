# apt packages for Streamlit Community Cloud.
#
# ultralytics imports cv2 unconditionally, and opencv-python links against
# libGL and glib. Neither is in the default Streamlit Cloud image, so without
# these the app dies at import with:
#
#     ImportError: libGL.so.1: cannot open shared object file
#
# Invisible locally, immediate in deployment. These are installed only when the
# container is BUILT, so adding this file to a running app requires a reboot
# (Manage app -> Reboot), not just a redeploy.
libgl1
libglib2.0-0
libsm6
libxext6
